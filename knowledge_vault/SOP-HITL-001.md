# Approval Workflow for Tier 3 Changes

- Every Tier 3 change waits in a pending state until a reviewer approves or rejects it.
- Approval expires after 24 hours. An expired request must be submitted again.
- A reviewer cannot approve a request they submitted. See [[POL-ACC-001]].
